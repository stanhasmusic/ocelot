# Difficulty is an absolute authored curve; the Hangar is a between-level catch-up, and skill substitutes for one tier

Difficulty across the four-level campaign is **authored as an absolute curve**, not scaled to player power. Each level is balanced for an *expected* Hangar tier (Pacific Beachhead → tier 0, Countryside → 1, City → 2, Naval → 3), and the **Hangar is the between-level pressure-release valve**: power jumps when you spend coins, the next level resets to its intro onramp and climbs higher than the last. Felt difficulty is therefore a **sawtooth**, not a smooth line. A skilled player can clear a level **one tier under** its expected tier — upgrades stay meaningful, but skill is always a valid currency, so no one hard-walls.

We picked this over (a) a **hard tier-gate** — clean economy math, but it walls a player who under-buys and forces grinding, which is hostile to the noob/mid-tier audience ([[project-ocelot-target-audience]]); (b) **pure-skill / Hangar-optional** — maximally fair but guts the metagame payoff, since there's no reason to visit the Hangar; and (c) **rubber-band scaling** (enemies level with the player) — this quietly nullifies every upgrade purchase, defeating the point of the persistent metagame ([[0005-persistent-campaign-with-hangar-metagame]]).

Consequence: the economy (PRD-11 / issue #39) must be tuned so that *buying sensibly* keeps the player at the level's expected tier while *playing well* buys ~1 tier of slack — that is the explicit target for the economy grill. Level tuning targets the expected tier, never the player's actual owned tier (no runtime scaling). The per-stage intro onramp ([[0002-hybrid-stage-difficulty]]) is what resets the sawtooth at the start of each stage and each level. The escalation cadence — which threat tiers, archetypes, and armor each level introduces — is the build spec and lives in the roadmap / level-content PRD, not here.
